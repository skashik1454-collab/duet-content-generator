# Duet Content Generator

An internal content generation tool for **Duet** couples question cards. Generate social media slideshow content and export cards directly from the curated Duet question library.

## ✨ Features

- **Semantic Question Search & Ranking**: Natural language matching and smart filtering across question categories and tags.
- **Customizable Question Cards**: Preview beautiful cards with custom typography, gradients, and styling.
- **Diversity & Novelty Selection**: Prevents repetitive questions and ensures varied tones and depth.
- **PNG Card Export**: High-resolution image export powered by `html2canvas`.
- **Question Library Management**: Built-in library upload and local persistence.

## 🛠️ Tech Stack

- **Vite** - Modern frontend build tool
- **Vanilla JavaScript (ES Modules)** - Clean, component-based modular architecture
- **html2canvas** - Card export and rendering
- **CSS3** - Glassmorphism, responsive layout, modern gradients

## 🚀 Getting Started

### Prerequisites

Ensure you have [Node.js](https://nodejs.org/) installed (v18+ recommended).

### Installation

```bash
# Clone the repository
git clone https://github.com/<your-username>/duet-content-generator.git

# Navigate to the project directory
cd duet-content-generator

# Install dependencies
npm install
```

### Development

Start the local development server:

```bash
npm run dev
```

### Build

Create an optimized production build:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```
